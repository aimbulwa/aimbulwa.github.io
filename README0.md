# aimbulwa.github.io

To create a professional academic website for a professor using GitHub Pages:

Use specialized templates like academicpages or al-folio. 

This approach removes the need to write complex HTML or CSS from scratch and automatically formats sections for publications, teaching history, and research lab updates.

Step 1: 
- Create a GitHub Account. Visit the GitHub Signup Page to create a free account.
- Choose a professional username (e.g., Profaimbulwa). Note: Your username will dictate your permanent web address: https://username.github.io.

Step 2: 
- Choose and Copy an Academic Template. Instead of coding from scratch, copy a pre-built structure optimized for academia:

Option A (Academic Pages - https://github.com/academicpages/academicpages.github.io): 
Best for clean layouts, markdown blogs, and structured cv lists.

Option B (al-folio - https://github.com/alshedivat/al-folio): 
A highly popular, feature-rich Jekyll theme featuring automated dynamic citations and analytics.

- To use one, log into GitHub, 
- Visit your chosen template repository, and click the green "Use this template" button (or Fork it) in the top-right corner.

Step 3: 
- Configure the Repository. Name the new repository exactly username.github.io (replace username with the actual GitHub account name).
- Ensure the repository visibility is set to Public so the page can be accessible.
- Click Create repository.

Step 4: 
- Activate GitHub Pages
- Open your newly created repository on GitHub.
- Click the Settings tab located in the top navigation bar.
- Select Pages from the left-hand menu bar (under "Code and automation").
- Under "Build and deployment", set the source to Deploy from a branch.
- Select the main (or master) branch and choose the /root folder.
- Click Save. 
- Your website will live at https://username.github.io within a few minutes.

Step 5:
- Customize Content & Publications. You can edit the files directly on the GitHub website using the pencil icon, or clone the repository to edit locally:

Global Settings (_config.yml): 
- Change the site name, professor's title, department info, and social links (like Google Scholar or ResearchGate).

Biography (index.md or index.html): 
- Edit this file to rewrite the homepage text, research summary, and upload a profile picture.

Publications & CV (_publications/ or _talks/): 
- Add markdown files for individual research papers or input them into the template's structured data files to cleanly format a dynamic CV.
